# 微信表情包制作 Skill

面向支持 `SKILL.md` 的 AI 助手，整理微信原创表情包从角色设定、独立循环 GIF 到配套图片、投稿文案和交付检查的工作流程。

## 能做什么

- 根据参考图保持角色、配色、配件和画风一致。
- 制作独立动作序列，合成循环 GIF，检查透明边缘和残影。
- 按需求制作封面、聊天图标、两类横幅及赞赏图片。
- 检查尺寸、真实格式、实际字节数与文案长度，整理交付文件。
- 单项任务只处理用户指定范围。

## 使用方法

下载本仓库，将包含 `SKILL.md` 和 `references` 的文件夹作为 `wechat-sticker-pack` 安装到所用助手的技能目录，然后在对话中调用 `$wechat-sticker-pack`，并提供角色参考、动作或文案、素材范围及署名。

示例请求：

> 使用 $wechat-sticker-pack，基于我上传的角色参考，制作 16 张独立循环表情和完整配套图片。先确认角色设计，文案每张优先不超过 4 个字。

> 使用 $wechat-sticker-pack，只修复这些 GIF 在黑底上的白色残留，保留眼白和文字描边，另存新版。

## 环境要求

需要可用的图像生成或编辑能力，以及图像处理、GIF 合成与文件检查环境。此仓库提供工作流程和参考资料，不附带图像生成服务、API 密钥或自动生成程序。静态生图结果需要另行合成动画；具体操作遵守宿主工具许可。

## 规格与案例说明

本项目不是微信官方项目。规格记录源于 2026 年 11 月的制作案例与用户提供的投稿页面截图；截图原件和角色参考图未随仓库发布。历史参数和实测体积不能替代当前投稿页面要求，尚未核实的标准已在参考文件中标注。

案例用于说明流程，不代表所有项目的默认角色。仓库不包含原始作品图片、个人聊天记录或本机环境路径，也不作平台审核或作品权属保证。
