# 强撑小土豆 Concept A（仅示例）

角色：暖黄色斑点土豆、绿色针织帽、倦怠半睁眼、深棕小手脚、桃色脸颊；软质3D潮萌风，强颜欢笑和贱萌反差。新角色不要继承这些外观。

16个动作：收到（敬礼）、好的好的（点头）、我没事（假笑冒汗）、哈哈哈哈（后仰大笑）、不想上班（趴倒）、救命（慌张挥手）、崩溃了（裂开复合）、有病吧（怒挥拳）、加班中（敲电脑）、我太难了（哭泣）、强撑一下（颤抖站起）、马上就好（急跑）、摸鱼（玩手机）、吃瓜（啃西瓜）、晚安（闭眼呼吸）、满血复活（跃起落地）。

横幅叙事：加班—强撑—摸鱼—复活；艺术家横幅：角色在温暖工作室绘制表情。
封面：全身强颜欢笑双手点赞；聊天图标：绿色帽子、疲惫脸的正面头部。
赞赏引导语：赏颗小土豆，明天继续撑。
致谢图文案：谢谢你的赞赏／小土豆满血复活啦！
介绍参考：戴着毛线帽的小土豆，嘴上说着“我没事”，内心早已裂开！陪你加班、摸鱼、假笑，偶尔崩溃，随时满血复活。

复用提示词骨架：
角色参考及不可变特征；本项用途；单一动作与首尾回位；画幅和安全边距；透明/不透明背景；文字原文或禁文字；是否允许描边；禁用多余角色和装饰；输出后另行做确定性尺寸/格式/体积校验。

本次经验：生图返回的是静态网格，不是GIF；透明预览可能显示奇怪底色，应检查实际alpha后判断；角色网格会有背景杂点，需要处理并重新目视检查；不应只检验文件属性就宣称动画流畅。不要跨项目硬编码本机字体、虚拟环境或历史图片路径。
